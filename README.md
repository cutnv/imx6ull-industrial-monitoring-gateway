# 基于 i.MX6ULL 的工业设备多协议数据采集与触控远程监控网关

基于 **ALIENTEK i.MX6ULL ALPHA V2.4** 开发板构建的嵌入式 Linux 工业监测项目。

项目从工业现场设备采集数据，在触控屏上完成本地状态显示、告警和交互，并通过网络把数据发送到远程监控端。它既是工业监测终端，也是连接现场总线与上层网络服务的边缘网关。

## 主要功能

- **工业数据采集**：以 CAN 为首个现场接口，后续按需要扩展串口及其他接口。
- **本地触控 HMI**：使用 7 英寸 RGB LCD 和 GT911 触摸屏显示设备状态、趋势和告警。
- **远程监控通信**：使用 Ethernet，并逐步加入 MQTT、HTTP、WebSocket 和 TLS。
- **边缘网关处理**：完成数据解析、状态判断、协议转换、缓存和转发。
- **系统工程实践**：覆盖 U-Boot、Linux、设备树、驱动、交叉编译、网络编程和应用开发。

## 硬件平台

- SoC：NXP i.MX6ULL
- 开发板：ALIENTEK i.MX6ULL ALPHA V2.4
- DDR：512 MiB
- eMMC：8 GB
- 显示：7 英寸 RGB LCD，1024 × 600
- 触摸：Goodix GT911
- 已使用接口：CAN、Ethernet、SD、eMMC、UART

## 当前进度

当前处于基础验证和板级准备阶段：

- 官方 SD 系统能够正常启动。
- LCD 显示与 GT911 触摸输入已验证。
- Ethernet 双向 ping 已验证。
- CAN 回环测试已验证。
- Ubuntu 交叉编译环境已准备。
- U-Boot 2024.10 已建立 ALIENTEK ALPHA V2.4 独立板级 target。
- 新 U-Boot 已能初始化 DDR、识别 SD/eMMC，并手动加载现有 Linux 镜像。

U-Boot 以太网、完整 eMMC 启动、Linux 设备树整理及正式监控应用仍待完成。

## 计划路线

1. 完成 U-Boot 板级外设移植和冷启动验证。
2. 整理 Linux 内核及设备树。
3. 实现 CAN 数据采集服务。
4. 实现触控 HMI。
5. 加入 MQTT、HTTP、WebSocket 和 TLS。
6. 完成数据存储、异常恢复、日志和系统部署。
7. 建立可重复的构建、烧写、测试和发布流程。

## 开发原则

- 每个阶段先验证最小闭环，再增加功能。
- 重要命令、硬件差异和故障原因都要记录。
- 生成文件、大型工具链和厂商压缩包不提交到仓库。
- 代码、配置、文档和测试结果随项目进度持续提交。
